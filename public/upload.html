Troubleshooting Steps:
1. Check if you're logged in with supplier role enabled
2. Verify API connectivity
3. Test unified authentication
4. Try uploading a small CSV file

Common Issues:
• "Invalid API key" → Your session may have expired, try logging in again
• "Cannot connect to API" → Make sure docker containers are running
• "Authentication failed" → Check that you have supplier role enabled
• "Upload feature only for suppliers" → Register with supplier role at /auth.html
